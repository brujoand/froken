# Curriculum data — source and licence

Everything under this directory is generated by `froken-ingest` from
Utdanningsdirektoratet's open Grep API. **It is not authored by this project and
must not be hand-edited** — corrections belong upstream, and a local edit would
be silently overwritten by the next ingest.

Inneholder data under [NLOD](https://data.norge.no/nlod/no), tilgjengeliggjort på
[data.udir.no](https://data.udir.no).

Contains data under [NLOD](https://data.norge.no/nlod/en), made available on
[data.udir.no](https://data.udir.no).

NLOD permits copying, redistribution, modification, merging with other datasets,
and commercial use, on these conditions:

- the source is credited, as above;
- the data is not presented in a misleading or distorted manner;
- Utdanningsdirektoratet's logo is not used without a separate agreement.

Competence-goal text is therefore reproduced verbatim, in the målform Udir
published it in. `manifest.json` records the curriculum code, validity window,
upstream `sist-endret` timestamp and a content hash for each subject, so any
copy can be verified against the official source.

Udir accepts no liability for errors in the data, and neither party's terms make
this project official or endorsed.
